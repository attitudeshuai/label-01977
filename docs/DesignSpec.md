> **项目名称**: Daily Journal (日记记录系统)  
> **设计版本**: v1.0  
> **设计理念**: 简约大气 · 专注写作 · 温暖可爱

---

## 1. 设计哲学

### 1.1 核心原则

| 原则 | 描述 |
|------|------|
| **专注** | 去除一切干扰元素，让用户沉浸在写作中 |
| **温暖** | 柔和的色彩和圆润的形状，营造舒适感 |
| **可爱** | 精心设计的图标和微动效，增添趣味性 |
| **呼吸感** | 充足的留白，让界面有呼吸的空间 |

## 5. 阴影系统 (Shadows)

### 5.1 阴影层级

| 名称 | 值 | 用途 |
|------|-----|------|
| **Shadow SM** | `0 1px 2px rgba(0,0,0,0.04)` | 输入框、小卡片 |
| **Shadow MD** | `0 4px 12px rgba(0,0,0,0.06)` | 卡片悬停 |
| **Shadow LG** | `0 8px 24px rgba(0,0,0,0.08)` | 模态框、下拉菜单 |
| **Shadow Glow** | `0 0 20px rgba(255,154,139,0.3)` | 主按钮发光效果 |

### 5.2 特点

- 阴影颜色使用低透明度黑色，保持柔和
- 避免硬边阴影，使用大模糊半径
- 主色按钮可使用发光阴影增加趣味性

## 8. 动效规范 (Animations)

### 8.1 基础过渡

| 类型 | 时长 | 缓动函数 | 用途 |
|------|------|----------|------|
| **快速** | 150ms | ease-out | 按钮状态变化 |
| **标准** | 250ms | ease-in-out | 卡片悬停、展开 |
| **慢速** | 400ms | ease | 页面切换、模态框 |

### 8.2 特色动效

| 名称 | 描述 | 用途 |
|------|------|------|
| **Bounce In** | 弹性进入 | 心情/天气选择反馈 |
| **Float** | 轻微上下浮动 | 空状态插画 |
| **Pulse Glow** | 发光脉动 | 保存成功提示 |
| **Slide Up** | 从下滑入 | 卡片列表加载 |

### 8.3 微交互

```css
/* 按钮悬停 - 上浮效果 */
.btn-primary:hover {
  transform: translateY(-2px);
  box-shadow: 0 0 20px rgba(255,154,139,0.3);
}

/* 卡片悬停 - 提升效果 */
.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 8px 24px rgba(0,0,0,0.08);
}

/* 心情选择 - 弹跳效果 */
.mood-item.selected {
  animation: bounceIn 0.3s ease;
  transform: scale(1.1);
}

/* 日历日期悬停 */
.calendar-date:hover {
  background: rgba(255,154,139,0.1);
}
```
