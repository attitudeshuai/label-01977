# 📝 心情随笔 - 需求规格说明书

> **项目名称**: 心情随笔 (日记记录系统)  
> **版本**: v1.0  
> **最后更新**: 2026-02-04

---

## 1. 项目概述

### 1.1 业务目标
构建一个现代化的个人日记记录 Web 应用，帮助用户记录日常生活、心情和思考。支持多用户独立使用，保障数据隐私。

### 1.2 核心价值
- **简洁高效**: 快速记录，降低书写门槛
- **安全私密**: 用户数据隔离，JWT 认证
- **美观现代**: 符合 Dribbble 标准的 UI 设计
- **容器交付**: 一键启动，即开即用

## 2. 功能需求

### 2.1 用户认证模块 (Auth)

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| AUTH-01 | 用户注册 | 邮箱/用户名 + 密码注册 | P0 |
| AUTH-02 | 用户登录 | JWT Token 认证 | P0 |
| AUTH-03 | 退出登录 | 清除本地 Token | P0 |
| AUTH-04 | 密码加密 | BCrypt 加密存储 | P0 |

### 2.2 日记管理模块 (Journal)

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| JOUR-01 | 创建日记 | 标题 + 富文本正文 + 心情 + 天气 | P0 |
| JOUR-02 | 日记列表 | 按时间倒序展示，支持分页 | P0 |
| JOUR-03 | 查看日记 | 日记详情页 (渲染富文本) | P0 |
| JOUR-04 | 编辑日记 | 修改已有日记内容 | P0 |
| JOUR-05 | 删除日记 | 软删除/硬删除 | P0 |
| JOUR-06 | 日记搜索 | 按标题/内容关键词搜索 | P1 |
| JOUR-07 | 心情标签 | 预设心情选项 (开心/平静/难过/愤怒/焦虑) | P1 |
| JOUR-08 | 天气记录 | 预设天气选项 (晴/多云/阴/雨/雪) | P1 |
| JOUR-09 | 富文本编辑器 | 专业排版工具 (Tiptap) 支持标题/加粗/列表/引用等 | P0 |

### 2.3 日历视图模块 (Calendar) 🆕

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| CAL-01 | 月历视图 | 按月展示日历，标记有日记的日期 | P0 |
| CAL-02 | 心情/天气标记 | 在日历日期上展示当日心情和天气图标 | P0 |
| CAL-03 | 日期点击 | 点击有日记的日期进入查看，无日记则进入新建 | P0 |
| CAL-04 | 月份切换 | 支持前后月份导航 | P0 |

### 2.4 数据统计模块 (Stats)

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| STAT-01 | 日记总数 | Dashboard 展示 | P1 |
| STAT-02 | 本月统计 | 本月日记数量 | P1 |
| STAT-03 | 心情分布 | 饼图展示心情占比 | P2 |

## 3. 非功能需求

### 3.1 技术栈

| 层级 | 技术选型 | 版本 |
|------|---------|------|
| **后端框架** | Spring Boot | 3.2.x |
| **安全框架** | Spring Security + JWT | - |
| **数据持久** | Spring Data JPA | - |
| **数据库** | MySQL | 8.0 |
| **前端框架** | Vue 3 (Composition API) | 3.4.x |
| **构建工具** | Vite | 5.x |
| **UI 框架** | Tailwind CSS | 3.x |
| **HTTP 客户端** | Axios | - |
| **路由** | Vue Router | 4.x |
| **状态管理** | Pinia | 2.x |
| **富文本编辑器** | Tiptap | 2.x |
| **日历组件** | 自研 (Tailwind) | - |
| **容器化** | Docker + Docker Compose | - |

### 3.2 UI/UX 设计理念 🎨

| 维度 | 要求 |
|------|------|
| **整体风格** | 简约大气 + 偏可爱风 |
| **核心体验** | 专注写作，减少干扰 |
| **色彩方案** | 柔和暖色调，浅色背景，圆角元素 |
| **字体** | 清晰舒适的无衬线字体，适合长时间阅读 |
| **图标** | 可爱风格 Emoji/图标 (心情、天气) |
| **动效** | 微妙柔和的过渡动画，不喧宾夺主 |
| **编辑体验** | 沉浸式写作模式，工具栏简洁不遮挡 |

### 3.3 性能要求

- API 响应时间 < 500ms (P95)
- 前端首屏加载 < 3s
- 支持 100 并发用户

### 3.4 安全要求

- 所有 API 需 JWT 认证 (除登录/注册)
- 密码 BCrypt 加密 (强度 10)
- 用户只能访问自己的日记数据
- XSS/CSRF 防护

## 4. 数据模型

### 4.1 用户表 (users)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| username | VARCHAR(50) | UNIQUE, NOT NULL | 用户名 |
| email | VARCHAR(100) | UNIQUE, NOT NULL | 邮箱 |
| password | VARCHAR(255) | NOT NULL | 加密密码 |
| avatar | VARCHAR(255) | NULL | 头像 URL |
| created_at | DATETIME | NOT NULL | 创建时间 |
| updated_at | DATETIME | NOT NULL | 更新时间 |

### 4.2 日记表 (journals)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| user_id | BIGINT | FK, NOT NULL | 用户外键 |
| title | VARCHAR(200) | NOT NULL | 标题 |
| content | TEXT | NOT NULL | 正文内容 |
| mood | VARCHAR(20) | NULL | 心情标签 |
| weather | VARCHAR(20) | NULL | 天气 |
| created_at | DATETIME | NOT NULL | 创建时间 |
| updated_at | DATETIME | NOT NULL | 更新时间 |
| deleted_at | DATETIME | NULL | 软删除时间 |

## 5. API 设计 (RESTful)

### 5.1 认证接口

| Method | Endpoint | 描述 |
|--------|----------|------|
| POST | `/api/auth/register` | 用户注册 |
| POST | `/api/auth/login` | 用户登录 |
| POST | `/api/auth/logout` | 退出登录 |
| GET | `/api/auth/me` | 获取当前用户信息 |

### 5.2 日记接口

| Method | Endpoint | 描述 |
|--------|----------|------|
| GET | `/api/journals` | 获取日记列表 (分页) |
| GET | `/api/journals/:id` | 获取日记详情 |
| POST | `/api/journals` | 创建日记 |
| PUT | `/api/journals/:id` | 更新日记 |
| DELETE | `/api/journals/:id` | 删除日记 |
| GET | `/api/journals/search?q=` | 搜索日记 |

### 5.3 日历接口

| Method | Endpoint | 描述 |
|--------|----------|------|
| GET | `/api/calendar/:year/:month` | 获取某月日记概览 (日期+心情+天气) |

### 5.4 统计接口

| Method | Endpoint | 描述 |
|--------|----------|------|
| GET | `/api/stats/overview` | 获取统计概览 |

## 6. 页面结构

| 页面 | 路由 | 描述 |
|------|------|------|
| 登录页 | `/login` | 用户登录 |
| 注册页 | `/register` | 用户注册 |
| 首页/Dashboard | `/` | 日记列表 + 统计卡片 |
| 日历视图 | `/calendar` | 月历展示心情/天气，点击跳转 |
| 日记详情 | `/journal/:id` | 查看单篇日记 |
| 写日记 | `/journal/new` | 创建新日记 (富文本编辑器) |
| 编辑日记 | `/journal/:id/edit` | 编辑日记 (富文本编辑器) |
| 按日期写日记 | `/journal/new?date=YYYY-MM-DD` | 从日历点击进入，预填日期 |
