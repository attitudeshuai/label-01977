## P1: 后端核心 (Backend Core)

### 目标
实现用户认证和日记 CRUD 的 RESTful API。

### 任务清单

| ID | 任务 | 描述 | 状态 |

| P1-01 | 用户实体 | User Entity + Repository | 🔲 |

| P1-03 | JWT 配置 | Spring Security + JWT 工具类 | 🔲 |
| P1-04 | 注册 API | POST /api/auth/register | 🔲 |
| P1-05 | 登录 API | POST /api/auth/login | 🔲 |

| P1-07 | 日记列表 API | GET /api/journals (分页) | 🔲 |
| P1-08 | 日记详情 API | GET /api/journals/:id | 🔲 |
| P1-09 | 创建日记 API | POST /api/journals | 🔲 |
| P1-10 | 更新日记 API | PUT /api/journals/:id | 🔲 |
| P1-11 | 删除日记 API | DELETE /api/journals/:id | 🔲 |
| P1-12 | 日历数据 API | GET /api/calendar/:year/:month | 🔲 |
| P1-13 | 搜索 API | GET /api/journals/search | 🔲 |
| P1-14 | 统计 API | GET /api/stats/overview | 🔲 |

### 验收标准
- [ ] 用户可注册/登录获取 JWT
- [ ] JWT 认证保护所有业务 API
- [ ] 日记 CRUD 功能完整
